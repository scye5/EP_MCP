## 第 4 层：MCP 协议层（需先装 mcp）

当前环境尚未安装 `mcp`。在 PyCharm 终端里执行：

```bash
pip install -e .        # 安装 mcp 并把 agn-mcp 注册为命令
agn-mcp                 # stdio 模式，供 Agent 连接
agn-mcp --transport sse --port 8000   # 或 SSE 模式，浏览器/HTTP 客户端连接
```

启动后用 MCP 客户端验证。最省事的是官方 Inspector（图形界面，能手动点每个 tool）：

```bash
npx @modelcontextprotocol/inspector python -m agn_mcp.server
```

Inspector 里应能看到 **14 个 tools、5 个 resources、4 个 prompts**：

- 试 `classify_agn`，填入：
  ```json
  {
    "object_id": "NGC 4151",
    "evidence": [
      {"id":"E1","value":{"fwhm_kms":3200}},
      {"id":"E7","value":{"lx_2_10":8.4e42}}
    ],
    "strategy": "purity"
  }
  ```
  预期返回 `label=CONFIRMED_AGN`、`score=4`。
- 试 `compute_bpt`，填 `log_nii_ha=-0.3`、`log_oiii_hb=1.0`，预期 `region=AGN`。
- 点 Resources 里的 `agn://criteria/evidence_table`，应返回 E1–E12 的 JSON 表。
- 点 Prompts 里的 `sop_single_object`，应返回 SOP 编排文本。

也可以用 Python 客户端做自动化协议测试（需要 mcp 装好后）：

```python
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    params = StdioServerParameters(command="python", args=["-m", "agn_mcp.server"], cwd="src")
    async with stdio_client(params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            tools = await session.list_tools()
            print("tools:", [t.name for t in tools.tools])
            r = await session.call_tool("classify_agn", arguments={
                "object_id": "T", "evidence": [{"id":"E1","value":{"fwhm_kms":3200}}]
            })
            print(r.content)

asyncio.run(main())
```

##  Troubleshooting

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: mcp` | 没装 mcp | `pip install -e .`；只测逻辑可跳过，走第 1–3 层 |
| `python examples/...` 找不到 agn_mcp | cwd 不对 | 必须在 `agn_mcp/` 根目录运行，脚本已自动插入 src 到 path |
| NED 请求超时 | 官网连接慢 | 调大 `NED_TIMEOUT=60` 或用 `NED_OFFLINE=1` |
| `classify_agn` 返回 `INDETERMINATE` | 证据不足是诚实出口 | 检查 evidence 是否为空或判据未达阈值；缺分类不等于非 AGN |
| 改了判据逻辑后测试变了 | 预期行为 | 重跑 `python -m unittest discover -s tests` 确认无回归 |

最大风险：MCP 协议层必须装 `mcp` 才能测，而当前环境的网络安装被拦截——这一层需要你在
本地终端自行完成。前三层不依赖 mcp，现在就能全跑通。
